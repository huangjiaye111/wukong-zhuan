悟空传 v74 · 离线便携版

开始游戏
1. 将整个“悟空传-v85”文件夹解压到固定位置，保留内部目录结构。
2. 用 Microsoft Edge 或 Chrome 打开 index.html，即可游玩，无需安装或联网。
3. 游戏面向电脑键盘与鼠标。首次进入可在标题页查看“操作说明”。

静音体验
在浏览器地址栏的 index.html 后添加 ?practice=1&silent=1。
该入口默认静音，进度只留在当前页面；刷新后重置，不改正式存档。
正式入口使用玩家自己的声音设置，可在设置页调整。

主要操作
A / D 或 ← / →：移动。K / W / ↑：跳跃，可二段跳。
J：普通三连击。U：重斩。I：烈焰闪。O：七十二斩。L：大闹天宫（无双）。
R：法宝主动技（需先在背包·法宝页装备）。
B：行囊（装备整理页可“推荐配装”，一键换上更优装备）。
P / C / M / N / V：伙伴 / 技能 / 仙坊 / 历练册 / 设置。Esc：暂停。
