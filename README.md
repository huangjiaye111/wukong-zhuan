# 造梦西游 · 悟空传（网页版）

西游题材同人作品 · 全部美术与音乐为本项目原创 · 不含原版素材。

## 怎么玩

直接打开本页即可游玩，进度自动保存在浏览器本地。

- A / D（或 ← →）：移动　K / W：跳跃（可二段跳）
- J：普通三连击　U / I / O：重斩 / 烈焰闪 / 七十二斩　L：无双
- R：法宝主动技（背包·法宝页装备后）　B / P / C / M / N / V：背包 / 宠物 / 技能 / 商店 / 成就 / 设置
- Esc：暂停

面向电脑键盘操作，建议使用 Microsoft Edge 或 Chrome。

## 离线游玩

下载仓库为 ZIP 解压后，直接双击 index.html 即可离线游玩。
